🚀 **Building an AI-Assisted SOC Automation Lab | Wazuh + n8n + Ollama**

I've been building a hands-on cybersecurity lab to explore how SIEM alerting, workflow automation, and local AI can work together in a SOC workflow.

🔧 **Project components**
- **Wazuh SIEM:** Security event monitoring and alert generation on Ubuntu Server in VMware.
- **n8n:** Docker-based workflow automation with a Webhook to receive Wazuh alerts.
- **Ollama:** Local LLM integration for explaining alert evidence and suggesting investigation steps.
- **Email notifications:** Extending the workflow to deliver alert summaries and AI-assisted triage to an analyst inbox.

🎯 **Next improvements**
- Severity-based alert filtering.
- Structured triage reports with evidence and uncertainty.
- Better error handling and test coverage.
- Threat-intelligence enrichment and human-approved response actions.

This project is helping me learn by building and troubleshooting the connections between tools—not just using them individually.
